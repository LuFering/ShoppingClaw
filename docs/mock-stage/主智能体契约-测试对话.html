通用观察点（每条都要看）

观察项应该看到什么
顶部定位发出消息后，你那条消息被钉在对话区最上方，AI 内容在其下方生长，不挤占上方空间；期间上方定位纹丝不动
滚动解锁你主动滚动鼠标滚轮 → 定位立即释放，之后可自由从头读到尾
卡片不自动收起对话结束后，「已调用 N 个工具」的工具汇总组仍然展开，不回缩
⭐ 叙述节奏每一段前置文本后面紧跟一个状态块（工具卡 / 子智能体卡 / 产物卡），不是开场白说一大段然后状态连滚
子智能体下钻子智能体开始干活时其卡片自动展开（下钻），干完后自动收起，视线交还主线
子智能体详情左侧子智能体卡默认展开，运行中就能看到调用工具/RAG/Skill 三段轨迹
右侧结果状态面板子智能体行可点击展开，显示「交付结果」文本
待办推进待办步骤按 pending → in_progress → completed 逐步变色，收尾全绿
编排卡内容有意图分诊 + 置信度 + Skill + RAG + MCP + 派遣清单 + 决策 + 护栏，不是空壳

出问题时怎么反馈给我

截图最好带这三处，我能直接定位：

  1. 编排卡的完整展开内容（意图分诊那一段是否渲染出来了）

常见假问题：
· 卡片样式不对但内容对 → 大概率是 vite 缓存，硬刷新
· 左侧空白右侧正常（或反之）→ 是"双存储透传"漏了字段，属于真 bug，告诉我字段名
· 待办空 → 该场景 mock 没发 plan 事件
