# 退换货与三包规则

> ⚠️ **本文是通用规则整理，不是某一平台的官方条款。**
> 各平台细则有差异，**具体以平台最新公示为准**。上线前请核对目标平台的实际规则。

## 七天无理由退货

**基本条件**
- 自**签收**之日起 7 天内（不是下单日）
- 商品**完好**，不影响二次销售
- 配件、赠品、包装齐全

**「完好」的界定**
- 服装：吊牌未拆、未洗涤
- 数码：未激活、未注册、无使用痕迹
- 美妆：未拆封（拆封后通常不适用）

## 不适用七天无理由的品类（常见）

| 品类 | 原因 |
| --- | --- |
| 定制商品 | 无法二次销售 |
| 鲜活易腐 | 时效性 |
| 在线下载/已拆封的音像制品 | 可复制 |
| 已拆封的数码产品 | 激活即贬值 |
| 贴身衣物、化妆品 | 卫生要求 |
| 报纸期刊 | 时效性 |

⚠️ **具体清单各平台不同**，且商家可在合规范围内自行标注。

## 三包（修理/更换/退货）

**时间节点**（多数品类适用）
| 时间 | 权利 |
| --- | --- |
| 7 天内 | 性能故障 → 可退、可换、可修 |
| 15 天内 | 性能故障 → 可换、可修 |
| 保修期内 | 性能故障 → 免费维修 |

**「性能故障」需符合产品说明书所列的故障情形**，人为损坏不在范围内。

## 运费谁承担

| 情形 | 运费承担方 |
| --- | --- |
| 七天无理由 | 通常买家 |
| 质量问题退货 | 商家 |
| 商家发错货 | 商家 |
| 三包期内维修 | 通常商家（大件可能双方分担） |

⚠️ 大件商品的运费（如家电）可能远高于商品本身价值，**退货前务必确认**。

## 保价（价保）

**与退货是两套机制**，别混用。
- 保价：买后降价可申请退差价
- 退货：不想要了，退回商品

**保价常见限制**
- 需在保价期内申请（通常 7–30 天）
- 需**同款同规格**，且需主动申请（不会自动退）
- 部分平台要求商品未拆封
- 用券购买的，差价计算方式可能不同

## 换货流程要点

1. 在平台内提交换货申请（不要只在聊天里说）
2. 按平台指引寄回（部分平台提供上门取件）
3. **保留寄回物流单号**
4. 收到换货后**当场验机**，有问题立即反馈

## 常见争议点

**「拆封了还能退吗」**
- 取决于品类和平台规则。数码产品拆封后通常只能走质量保修。
- 部分平台有「拆封无忧」服务，属于额外保障。

**「赠品要不要退」**
- 通常需要一并退回，否则可能从退款中扣除赠品价值。

**「用了优惠券的订单退款怎么算」**
- 通常按**实付金额**退，优惠券是否返还看平台规则。

**「超过 7 天还能退吗」**
- 质量问题可走三包；非质量问题通常不能。

## 操作建议

**买前**
- 确认商品是否支持七天无理由
- 确认退货运费谁承担
- 留意是否赠送运费险

**退货时**
1. **全程录像**打包过程（证明寄出时的状态）
2. 保留快递单号
3. 在平台内走流程，保留沟通记录
4. 关注退款到账时间（通常 3–7 个工作日）

⚠️ **不要私下寄回**（不经平台流程），出问题无法追溯。
