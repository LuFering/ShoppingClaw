# 价格陷阱识别

## 四类常见价格手法

**① 先涨后降（虚假折扣）**
- 大促前抬高原价，再「打折」到与平时相当甚至更高。
- **识别**：用比价工具看**历史价格曲线**，不看「原价」标注。
- **识别**：所谓「原价」常是厂商建议零售价（MSRP），从未真实成交过。

**② 划线价虚高**
- 页面上划掉的「原价 999」可能从未存在，只是为了衬托现价。
- **识别**：看该商品**近 90 天的真实成交价区间**。
- ⚠️ 部分平台对「划线价」有合规要求，但执行参差。

**③ 低价诱导（钓鱼价）**
- 用极低价吸引点击，实际发的是低配版、瑕疵品、或干脆不发货。
- **识别**：看 SKU 是否对应你看到的那个价格（低价常对应最差配置）。
- **识别**：看店铺是否有大量「未按约定发货」的投诉。

**④ 定金/预售套路**
- 定金不退、尾款时间短、尾款价高于预期。
- **识别**：**定金通常不退**（与订金不同），确认前想清楚。
- **识别**：算清「定金 + 尾款」的实际总价，不要只看尾款。

## 需要警惕的促销话术

| 话术 | 实际情况 |
| --- | --- |
| 「全年最低价」 | 无法验证，且常与日常价相当 |
| 「限时秒杀」 | 制造紧迫感，可能长期都在「秒杀」 |
| 「买贵退差价」 | 通常有严苛条件（需同款同店、需主动申请、有时效） |
| 「满减凑单」 | 为凑单买不需要的东西，实际支出更高 |
| 「赠品价值 XXX 元」 | 赠品价值常按标价算，实际价值远低 |

## 实操建议

**买前必做**
1. 用比价插件/工具看**历史价格曲线**（至少 90 天）
2. 对比**多个平台**同款价格
3. 算**到手价**（含运费、含券、含赠品折价），不只看标价
4. 确认**保价规则**：是否支持、保价期限、如何申请

**大促期间**
- 提前加购物车，记录价格，大促时对比
- 关注「价保」而非「折扣幅度」
- 警惕「先涨价再发券」

## 常见误区

- **「打折就是便宜」**：折扣是相对「原价」的，而原价可能是虚的。
- **「大促一定最便宜」**：部分品类大促价格与日常持平，甚至更高。
- **「领了券就划算」**：券常有使用门槛，可能诱导你买更贵的。
- **「保价了就放心」**：保价通常有诸多限制（同款同规格、需主动申请、有时效）。

## 争议处理

如果发现买贵了：
1. 截图保存**当时的页面价格**和**历史价格**
2. 在保价期内通过平台官方渠道申请
3. 保价失败可投诉「虚假宣传」（需举证原价不实）
4. ⚠️ 保留证据，不要只和客服口头沟通
