# 护肤品选购决策标准

## 先认清肤质（决定能不能用）

| 肤质 | 特征 | 选购方向 |
| --- | --- | --- |
| 油性 | 全脸出油、毛孔明显 | 清爽型、控油、水杨酸 |
| 干性 | 紧绷、起皮 | 滋润型、封闭性成分 |
| 混合 | T 区油、脸颊干 | 分区护理或选平衡型 |
| 敏感 | 易泛红、刺痛 | 精简配方、避开刺激成分 |

⚠️ 肤质会随季节、作息变化，不是固定标签。

## 核心成分怎么看

**保湿类（几乎所有人都需要）**
- **玻尿酸（透明质酸）**：吸水，需配合封闭剂锁水，单用会越用越干。
- **神经酰胺**：修护屏障，敏感肌友好。
- **角鲨烷**：接近皮脂，亲肤性好。

**功效类（需建立耐受）**
- **烟酰胺**：美白、控油。浓度 2–5% 有效，超过 10% 刺激性上升但效果不线性增加。
- **维 C（抗坏血酸）**：抗氧化、提亮。**易氧化变色**，看包装是否避光、是否含稳定衍生物。
- **视黄醇（A 醇）**：抗老、改善细纹。**必须建立耐受**，从低浓度低频开始，且需防晒。
- **果酸/水杨酸**：去角质。水杨酸适合油皮，果酸适合干皮。不可与 A 醇同用。

## 看配方而不是看宣传

- **成分表按浓度降序排列**。排在前面的才是主要成分，排在防腐剂之后的属于「概念添加」。
- 常见防腐剂（苯氧乙醇、对羟基苯甲酸酯）是安全的分界线参考位。
- **「无添加」不等于安全**，只是不含特定防腐剂，可能用别的替代。

## 剂型选择

- **精华**：活性成分浓度最高，价格最贵。
- **乳液**：清爽，适合油皮/夏季。
- **面霜**：封闭性强，适合干皮/冬季。
- **顺序**：从稀到稠（水 → 精华 → 乳液 → 面霜）。

## 常见误区

- **「贵的一定好」**：护肤品的溢价大量在品牌和包装，核心成分成本占比低。
- **「成分越多越好」**：成分越多，过敏风险越高。敏感肌应选精简配方。
- **「立刻见效才是好产品」**：除保湿外，美白/抗老通常需要 4–8 周。
- **「叠加越多越有效」**：活性成分叠加容易刺激，尤其是酸类 + A 醇。

## 按需求的取舍建议

- **只求保湿**：玻尿酸 + 神经酰胺的基础款即可，不必买贵的。
- **想美白**：烟酰胺或维 C，坚持 2 个月以上再判断。
- **抗老**：A 醇是证据最充分的，但必须配防晒。
- **敏感肌**：优先修护屏障（神经酰胺），暂停一切功效型产品。
