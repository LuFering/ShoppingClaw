# 床品选购决策标准

## 四件套

**看支数（纱线粗细）**
- 支数越高，纱线越细，手感越柔软。但**不是越高越好**。
- 40 支：日常够用；60 支：明显细腻；80 支以上：接近丝滑，但易勾丝、更贵。
- ⚠️ 部分商家标「160 支」实为**双股 80 支**，数字是乘出来的，不等于实际细腻度。

**看材质**
| 材质 | 特点 | 适合 |
| --- | --- | --- |
| 纯棉 | 透气、耐洗 | 全年通用 |
| 长绒棉 | 更长纤维，更柔软耐用 | 追求品质 |
| 天丝/莱赛尔 | 凉滑、垂坠 | 夏季、怕热 |
| 磨毛 | 表面起绒、保暖 | 冬季 |
| 聚酯纤维 | 便宜、不易皱 | 预算有限 |

**看密度**：密度（根/英寸）低于 200 会稀薄透光，300 以上算厚实。

## 枕头

**看睡姿**
- **仰睡**：中低枕（8–10cm），维持颈椎自然弧度。
- **侧睡**：高枕（10–15cm），填补肩膀到脖子的空隙。
- **俯睡**：薄枕（< 8cm）或不睡枕。

**看材质**
- **记忆棉**：贴合好、支撑强，但夏天偏热、有味道。
- **乳胶**：弹性好、透气，但偏重、价格高。
- **羽绒**：柔软可调，但支撑弱、需拍打。
- **荞麦/决明子**：硬度高、可塑形，但偏硬有噪音。

**高度可调**是加分项 —— 多数人需要试错才能找到合适高度。

## 被子

**看填充物**
| 填充 | 保暖/重量比 | 特点 |
| --- | --- | --- |
| 羽绒 | 最高 | 轻、蓬松，但怕潮、贵 |
| 蚕丝 | 高 | 贴身、透气，但不能水洗 |
| 化纤 | 低 | 便宜、可机洗，但闷 |
| 棉花 | 中 | 厚重、天然 |

**羽绒看两个数**
- **充绒量（g）**：越多越暖。冬被一般 1000–1500g。
- **蓬松度（FP）**：越高越保暖轻便。600 是入门，800 以上属高端。
- ⚠️ **含绒量**（90%、95%）指绒子比例，和蓬松度是两回事。

**看克重（化纤被）**：冬被 2000g 以上，春秋被 1000–1500g，夏被 500g 以下。

## 常见误区

- **「支数越高越好」**：80 支以上容易勾丝，且性价比下降明显。
- **「羽绒被越重越暖」**：保暖靠蓬松度锁住的空气层，不是重量。
- **「蚕丝被能水洗」**：多数不能，洗后会结块失去蓬松。
- **「四件套买贵的就耐用」**：耐用性主要看密度和缝纫，不只看价格。

## 按需求的取舍建议

- **怕热/夏季**：天丝四件套 + 薄化纤被。
- **怕冷/冬季**：磨毛四件套 + 羽绒被（或厚化纤被）。
- **颈椎不适**：优先解决枕头，记忆棉或可调高度的。
- **预算有限**：四件套买 60 支纯棉（性价比最高），被子可先用化纤。
