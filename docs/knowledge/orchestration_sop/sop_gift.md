# 送礼推荐的编排模板

## 适用场景

用户要「给某人挑礼物」，通常带预算、场合（生日 / 节日 / 纪念日）、收礼人身份。

## 编排路线

1. **只派购前助手**（一轮拿全）。任务描述里带上：收礼人身份、场合、预算、以及
   「实用不闲置」这类硬约束。
2. 推荐交付后，**若用户做出选择或表达偏好**，再派购后助手归档。

## 并行还是串行

串行。购后助手的归档依赖购前助手给出的候选结论 —— 没有结论时归档是空的。

## 关键约束

- 收礼人身份必须写进任务描述（给妈妈和给同事是两个完全不同的任务）
- 「忌讳」类信息（不收鲜花、不要闲置）要显式传递，不能指望购前助手猜到
- 不要在第一轮就派购后助手 —— 那时还没有可归档的决策

## 汇总话术

按「送谁 + 场合」组织，突出每款的适配人群，末尾给一个收窄方向
（如「如果她更在意实用，我可以再筛一轮」）。
