# 横向对比的编排模板

## 适用场景

用户已有一个以上具体候选，要「哪个更好」「差异在哪」「值不值」。

## 编排路线

1. **只派购前助手**，任务描述里列出全部候选（品牌 + 型号）。
2. 明确要求「基于同一组维度横向比较」，而不是逐款单独介绍 ——
   逐款介绍会让用户自己找差异，等于没做对比。
3. 用户选定后，派购后助手归档。

## 并行还是串行

串行。对比需要同一次任务里看到全部候选，拆成多次会失去可比性。

## 关键约束

- 候选必须写在**同一条**任务描述里，不要一个候选派一次
- 要求购前助手给出「决定性差异」而不是罗列参数
- 如果候选跨平台（京东 / 淘宝），要在汇总时说明价格口径差异

## 汇总话术

先给一句取舍主轴（如「真正的分岔点是头戴还是入耳」），
再按场景给建议，不要逐款复述参数（卡片前导已经讲过）。
