# 使用复盘的编排模板

## 适用场景

用户提到「已买」「用了几天」「值不值」「买亏了吗」这类**购后反馈**。

## 编排路线

1. **先派购后助手**：它持有 `recall_past_decisions` 与 `get_user_shopping_context`，
   能查出这条购买记录与当时的决策依据。
2. 若用户还想要「同价位有没有更好的」，**再派购前助手**做一轮对比。
3. 复盘结论由购后助手写回档案（`write_review`）。

## 并行还是串行

串行，且**购后优先**。复盘要基于「当时为什么这么选」，
这个信息只有档案里有；先派购前会丢失对比基线。

## 关键约束

- 不要凭记忆复盘 —— 必须先查档案拿到当时的决策依据
- 复盘要落到「下次怎么选更好」，不只是「这次买得对不对」
- 若档案里没有这条记录，如实说明，不要编造当时的理由

## 汇总话术

先给结论（值 / 不值 / 看场景），再说依据，最后给一条可复用的经验。
