# 写寄语

寄语是整份礼物唯一的「解释」：它把一堆商品变成一段话。

**判据**：把这段寄语里的任何一句拿出来，能不能指回前面某一步的依据？
指不回去，那句就是废话。

---

## 1. 素材从哪来

按顺序取，**都用真实产物，不另起炉灶**：

| 素材 | 来源 |
|---|---|
| 这次挑了哪几件 | 组合方案 `plan.items` |
| 为什么是这几件 | 「当前理解」`understanding.text` |
| 要避开什么 | 禁忌组（通常不写进寄语，但影响措辞） |

---

## 2. 三段结构

1. **称呼** —— 按关系来（妈 / 老王 / 张总），不用通用「亲爱的」
2. **说清是什么** —— 挑了哪几件，一句话
3. **为什么** —— 这是核心，要落到「她会真的用上」

**收尾**给一句轻的，不要升华。送礼是件轻的事，用力过猛反而尴尬。

---

## 3. 语气

| 关系 | 语气 |
|---|---|
| 长辈 / 父母 | 平实、少形容词；「我知道你不喜欢我乱花钱」比「感恩您的养育」好 |
| 伴侣 | 具体到细节；提一件只有你们知道的小事 |
| 同事 / 朋友 | 克制、不煽情；一句到位 |
| 客户 | 得体、不套近乎 |

**统一禁忌**：不用「感恩」「一路有你」「未来可期」这类模板句。
它们放在任何人身上都成立 —— 那就不成立。

---

## 4. 不写进寄语的

- 价格、折扣、购买渠道（礼物的背面不该出现）
- 你自己的辛苦（「挑了很久」可以说，但要轻，不要邀功）
- 禁忌本身（避开就行，不要在卡片上提醒对方有什么毛病）

---

## 5. 自检

写完问自己：

1. 这段寄语换一个人收，还成立吗？**成立就重写。**
2. 里面有没有一句是「指得回依据」的？**没有就重写。**
3. 读起来像不像人会说的话？**不像就重写。**
