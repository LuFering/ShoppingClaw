# 挑礼物：先定方向

「给 X 送什么」的答案要搜，但**搜什么**要先推。

方向错了，搜得越勤越尴尬：给同事搜高端香水（越界），给「爱喝茶的妈妈」搜保温杯（不搭边）。

这一步的产出不是商品，是**两三条路线 + 每条的一句话说法**——后面的检索从这里出发。

---

## 一、三条轴：关系 → 场合 → 预算

### 关系决定「礼物的语言」

| 关系 | 礼物的语言 | 天然方向 |
|---|---|---|
| 父母 / 长辈 | 关怀 + 实用体面 | 健康、家务减负、贴身温暖 |
| 伴侣 | 情感表达 + 仪式感 | 记忆点、佩戴物、共同体验 |
| 同事 / 上下级 | 分寸 + 不越界 | 桌面小物、办公实用、品牌文创 |
| 朋友 | 投其所好 | 兴趣相关、体验类 |

**关系的第一判据是「分寸」**：同事之间，礼物重了是负担、私人了是冒犯。

### 场合决定「分量」

生日 / 纪念日 / 婚礼——可以重一些、带仪式感；
入职 / 探访 / 答谢——轻一些、偏实用。
同一预算，不同场合的方向完全不同。

### 预算决定「档位心理」

- **预算不是「越多越好」，是关系的刻度尺**——500 送同事是心意，5000 送同事是压力
- 预算要和方向匹配：「800 送妈妈」允许一件有品牌的主力；「300 送同事」更适合"一件品牌小物 + 体面包装"
- 预算要留组合空间（单价超总预算 60% 的通常要排除）——细节见 `budget-balance`

## 二、方向线地图（从这六条里挑 2–3 条）

| 方向线 | 是什么 | 判据 / 风险 |
|---|---|---|
| **实用改善线** | 她每天都在用、但用得不够好的东西（保温杯、台灯、护手霜） | 礼物感来自"你注意到了"；能说清"替换掉什么" |
| **健康关怀线** | 按摩仪、足浴、体检 | 分寸是命门：说成"替你分担疲劳"，别说成"你身体不行" |
| **家务减负线** | 扫地机、洗碗机这类 | 前置条件："有人愿意帮她装、帮她维护吗"——否则是摆设 |
| **仪式情感线** | 饰品、真丝、香气 | 承载"被记住"的瞬间，适合生日 / 纪念日 |
| **兴趣投喂线** | 她本来就喜欢的东西的升级版（爱喝茶 → 好茶具；爱花 → 鲜花订阅） | 用户话说得越具体，这条线越准 |
| **体验记忆线** | SPA、演出、旅行、写真 | 不可囤积、记忆点强；需要她"愿意被安排" |
| **桌面办公线** | 文创、收纳、保温杯（同事专用） | 不挑人、不越界，是同事关系的安全区 |

**选路线的自检：这条线上，你能说出一句「为什么是她」吗？** 说不出就换一条。

> 实测（生产对话）：同一份「妈妈生日 1500 预算」的需求，好的产出是给出
> 「健康减负 / 家务减负 / 贴身情感 / 佩戴仪式感」四条不重叠的主线，让用户按妈妈的性格选；
> 差的产出是四条线其实是一类东西，或者干脆只给一堆商品。

---

## 三、从方向到搜索

方向定完，检索关键词**从方向线出发，不要从「礼物」出发**：

- ✅ 实用改善线 → 搜「保温杯 品牌」「护手霜 礼盒」
- ❌ 搜「送妈妈的礼物」——出来的全是礼盒包装、代写信、鲜花速递

具体品类词策略见 `composing-gift`；禁忌过滤以 `screening-taboos` 为准。

## 四、产出物

一份**方向清单**，交给用户在方向层面先做选择：

1. **2–3 条主方向线**，每条一句话：「这条线上送什么 + 为什么适合她」
2. 每条线对应的**预算档位**（预算怎么分到线上）
3. 如果几条线并列，给用户一个**能拍板的问题**（不含糊：「你更想让她在生日当天被记住，还是每天用得上？」）

**示例产出**（「800 送妈妈，生日」）：

> - **珍珠线（仪式感）**：生日当天能戴上、撑场面，预算 400–700 有体面的品牌款
> - **羊绒线（实用体面）**：秋冬天天披，老字号 + 礼盒送得出手，500–700
> - **健康线（打底）**：颈肩按摩仪 150–300，天天用、踩雷成本最低，可和上面叠搭
>
> 你更想让她「生日当天被记住」，还是「秋冬每天用得上」？

---

## 五、常见错误

1. **跳过方向直接搜**——搜出一堆"热销品"，没有一个是"给她的"
2. **一条线走到黑**——只搜饰品，错过"她其实更想要实用"
3. **方向掺假**——把"我觉得高端"当方向。方向必须锚在：关系、场合、预算、已知偏好
4. **线太多太碎**——五六条其实就是没方向；2–3 条，每条能独立成为一个选项

---

## 自检

1. 我挑的 2–3 条线，每条都指得回「关系 / 场合 / 预算 / 已知偏好」吗？
2. 每条线，能不能说出一句「为什么是她」？
3. 有没有跨过分寸线（同事送香水、长辈送暗示衰老的东西）？
4. 给用户的拍板问题，是具体的二选一，还是含糊的"你想送什么"？
