# 真实案例

> 数据来源：生产环境 `conversations` 表 40 段对话（2026-10 导出），
> 共 124 张商品卡。以下都是**真实出现过的**店铺名和价差。

---

## 案例 1 · 同款同店，价差 153 元

```
倍思 m4s 蓝牙耳机-55dB 主动降噪入耳式无线26新款
    ¥329   baseus倍思旗舰店
    ¥176   baseus倍思旗舰店     ← 同一家店！
```

**同一家官方旗舰店，同一款，差 153 元。**

这**不是假货问题** —— 店铺是完全可信的。价差来自：

- 不同时期的促销（百亿补贴 / 限时券）
- 不同 SKU 链接（同一个商品可能挂了多个推广链接）
- 标题里的「26新款」可能是不同批次

**处理**：两个都可信。选便宜的那个，并在 `risks` 里提示
「同款不同链接价差 153 元，下单前确认优惠是否叠满」。

**这个案例说明**：**价差不一定是坑**。同一家官方店都能差这么多，
所以不能一看到价差就怀疑。

## 案例 2 · 价格为 0 的异常卡

```
华为 FreeBuds SE 3 真无线蓝牙耳机（流光金）
    ¥0     华为京东自营店     ← 价格为 0
    ¥249   华为京东自营店
    ¥249   华为京东自营店
```

**`picks` 的硬性要求是 `price > 0`** —— 这张 ¥0 的卡**不该被渲染出来**。

来源：搜索接口偶发返回 `price: 0`（通常是特价活动价或字段缺失），
而校验没拦住。

**处理**：价格为 0 或拿不到价格的商品，**一律不进 `picks`**。
在 `no_recommendation_reason` 或 `risks` 里说明「部分候选的价格未能获取」。

## 案例 3 · 同款不同店（iPhone）

```
Apple iPhone 17 256GB 白色 5G 双卡双待
    Apple 官方旗舰店
    京东 Apple 自营
```

**两家都是高可信**（官方旗舰店 + 平台自营）。价格相同。

**处理**：都可信，差异在**售后渠道**（官方店走品牌售后，京东自营走京东售后）。
这类差异可以写进 `tradeoffs.reason`，帮用户按售后偏好选。

## 案例 4 · 店铺名的可信度分级

从 76 个真实店铺名里，能清楚看出命名规律：

**高可信（品牌方自己开的）**

```
索尼官方旗舰店         BOSE官方旗舰店        beats官方旗舰店
华为官方旗舰店         漫步者官方旗舰店      小米官方旗舰店
JBL耳机旗舰店         罗技官方旗舰店        希诺旗舰店
Apple 官方旗舰店       天猫超市             京东自营
华为京东自营店         漫步者京东自营店      OPPO京东自营店
```

**中可信（授权经销商 / 企业店）**

```
漫步者靓敏专卖店       索尼天星奥美专卖店     漫步者正乾专卖店
philips飞利浦轩耐专卖店  孩视宝护眼灯企业店
```

**低可信（个人或小卖家）**

```
果粉Store正品店        ← 自称"正品"恰恰可疑
BW宝华国行正品店        ← 同上
帝王国际通讯
唐麦旗舰店              ← 「旗舰店」但非知名品牌，需核实
```

**无法判断**

```
未知店铺                ← 拿不到店铺信息，最保守处理
```

### 关键观察

**在店名里强调「正品」的，反而要警惕。**

正规渠道（官方旗舰店、自营）**不需要**在名字里说自己是正品 ——
这是常识性信任。需要强调的，通常是渠道来路需要说明的。

这不是绝对判据，但是一个**值得多看一眼**的信号。

## 案例 5 · 价差的结构性来源

把上面的案例归纳一下，**同款价差**通常来自五类原因：

| 来源 | 是否可信 | 怎么识别 |
|---|---|---|
| **促销时间差** | ✅ 可信 | 同店同款，价差来自活动 |
| **渠道让利** | ✅ 可信 | 专卖店/自营 vs 官方店，正规经销商 |
| **SKU 链接不同** | ✅ 可信 | 同店同款挂了多条推广链接 |
| **规格/版本不同** | ⚠️ 要看清 | 标题里有容量、版本、套装差异 |
| **配件 / 二手 / 翻新** | ❌ 排除 | 标题含「保护套」「官换」「95新」「官翻」 |

**前三条是正当的**，后两条要用第三步的商品名比对挡掉。

## 常见误判

**误判 1 · 看到便宜就怀疑**

同店同款都能差 153 元（案例 1），价差本身不是可疑信号。
要看的是**店铺类型**和**商品名是否一致**。

**误判 2 · 看到「旗舰店」就放心**

`唐麦旗舰店` 里也有「旗舰店」三个字，但唐麦不是知名品牌，
这类需要核实是否为品牌方直营。

**误判 3 · 忽略「同款不同配」**

标题里多一个字（「保护套」「套餐」「官换」）就是不同的东西，
不能放在一起比价，更不能当成「同款更便宜」推荐给用户。
