# 同款比价

搜一个品类回来，经常出现这种情况：**同一个东西，价格差好几倍。**

```
索尼 WH-1000XM5    ¥1439   索尼官方旗舰店
索尼 WH-1000XM5    ¥899    未知店铺        ← 差 540，能买吗？
```

这个技能解决的就是：**怎么判断便宜的那个是真便宜还是坑。**

---

## 什么时候用

- 搜索结果里出现**同名商品、价格差异明显**（差 30% 以上）
- 用户主动问「这家这么便宜靠谱吗」「为什么差这么多」
- 你自己拿不准某个低价候选该不该进 `picks`

**不用的时候**：只有一个候选、或者价格本来就接近（差 10% 以内），不必走这套流程。

---

## 判断流程（四步）

### 第一步：找出「同款组」

把搜索结果按**商品名**聚类。同一款的不同卖家，归成一组。

**怎么算同款**：品牌 + 型号一致。看标题里的关键标识：

| 标题 | 同款吗 |
|---|---|
| `索尼 WH-1000XM5 头戴式降噪耳机` vs `Sony WH-1000XM5 无线降噪` | ✅ 同款（品牌+型号一致） |
| `索尼 WH-1000XM5` vs `索尼 WH-1000XM6` | ❌ 不同款（型号不同） |
| `华为 FreeBuds SE 3` vs `华为 FreeBuds SE 3 保护套` | ❌ 一个是配件，见第三步 |

只对**价格差 30% 以上**的组走后面三步。差得少的直接按正常流程处理。

### 第二步：看店铺名（最有效的单一信号）

淘宝的店铺名**自己会标类型**。这是判断的第一手依据：

| 店铺名里出现 | 含义 | 可信度 |
|---|---|---|
| `官方旗舰店` | 品牌方自己开的 | 最高 |
| `自营` / `京东自营` / `天猫超市` | 平台自己进货卖 | 高 |
| `XX专卖店` | 授权经销商 | 中高 |
| `XX企业店` | 企业资质，但未必授权 | 中 |
| 人名 / 谐音 / 无规律命名 | 个人或小卖家 | 低 |
| `未知店铺` | 拿不到店铺信息 | 最低 |

**真实例子**（从 40 段生产对话里统计的 76 个店铺名）：

- 高可信：`索尼官方旗舰店`、`BOSE官方旗舰店`、`天猫超市`、`华为京东自营店`
- 中可信：`漫步者靓敏专卖店`、`philips飞利浦轩耐专卖店`、`孩视宝护眼灯企业店`
- 低可信：`果粉Store正品店`（自称正品）、`帝王国际通讯`、`BW宝华国行正品店`
- 最可疑：`未知店铺`

**注意**：`果粉Store正品店` 这种「自己说自己正品」的命名，恰恰是**需要警惕**的信号 ——
正规渠道不需要在店名里强调正品。

### 第三步：比对商品名（排除「同款不同配」）

价格差得离谱，很多时候是**名字像但东西不一样**。逐项比：

| 差异类型 | 例子 | 判断 |
|---|---|---|
| 配件 vs 主机 | `FreeBuds SE 3` vs `FreeBuds SE 3 保护套` | 低价的是配件，**不是同款** |
| 简配 vs 标配 | `官方标配` vs `含充电盒套装` | 去掉套餐后的价，可能合理 |
| 容量/规格 | `256GB` vs `128GB` | 不同规格，**不可直接比价** |
| 版本 | `国行` vs `港版` / `海外版` | 版本不同，保修可能不适用 |
| 新旧 | `全新` vs `95新` / `官翻` | **二手或翻新**，不是新品 |

**这一步能解释掉大部分价差。** 如果低价的那个是配件、简配、二手，
那就不是「同款更便宜」，而是**另一个东西** —— 不该和正品放在一起比价。

### 第四步：定论（三档）

走完前三步，对每个可疑低价候选给一个结论：

| 档次 | 什么时候 | 怎么处理 |
|---|---|---|
| **可信** | 店铺是官方/自营，且商品名完全一致 | 正常进 `picks`，价格就是真实优势 |
| **要问清** | 店铺是专卖店/企业店，或商品名有小差异 | 可以进 `picks`，但**必须**在 `risks` 里写清要确认什么 |
| **排除** | 是配件/二手/翻新，或店铺明显异常 | 进 `rejected`，写明排除原因 |

---

## 产出物

走完流程，你要产出两样东西：

**① 可疑候选的结论** —— 写进 `tradeoffs` 或 `rejected`

```
{"sku_id": "...", "verdict": "exclude", "reason": "同款价差 540 元，低价方为『未知店铺』且标题含『官换机』，属翻新"}

{"sku_id": "...", "verdict": "pick", "reason": "同款价差 300 元，低价方为『XX专卖店』（授权经销商），标题与官方版一致，价差来自渠道让利"}
```

**② 要给用户确认的信息** —— 写进 `risks`

```
"低价方为『果粉Store正品店』（非官方渠道），下单前确认是否支持官方保修"
```

---

## 红线

- **不要因为便宜就排除** —— 授权经销商确实能比官方店便宜，那是正当让利
- **不要因为店铺名好听就采信** —— 「正品店」是自称，要看是不是官方/自营
- **拿不准就说拿不准** —— 写进 `risks` 让用户确认，比强行下结论好
- **不要编造店铺信息** —— `shop_name` 是什么就写什么，不知道就是「未知店铺」

---

## 自检

1. 我找到「同款组」了吗？还是把不同规格的东西放在一起比了价？
2. 价差我用**店铺类型 + 商品名差异**解释掉了吗？
3. 如果解释不掉，我是不是该把它列进 `risks` 让用户确认？
4. 我排除一个候选时，理由**具体到**店铺名和标题差异了吗？
